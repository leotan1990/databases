隐私政策

自然沉浸 (Aura 助眠) / Aura Sleep

最后更新日期：2026 年 10 月 28 日

1. 概述与核心承诺

欢迎使用“自然沉浸”（英文名称：Aura Sleep，以下统称“本应用”）。本应用由独立开发者开发与运营，提供环境音混音与声音创作工具。

核心承诺：本应用不包含第三方广告 SDK，不使用第三方行为追踪或分析 SDK，也不出售您的个人数据。应用在设备本地处理和保存音频及混音设置；用户主动分享和系统备份的情况见下文。如果您选择发送反馈，第 2 节所述的反馈数据会通过 Apple CloudKit 发送给开发者。

2. 系统权限与数据处理

本应用在您的设备上处理音频，仅在录音时申请麦克风权限。发送反馈是单独且自愿的操作。

  • 麦克风权限（可选）：当您开始录音时，应用会请求麦克风权限。录制的音频在本地处理并保存在应用的本地存储中。拒绝麦克风权限会使录音功能不可用，但不影响其他播放与混音功能。
  • 本地音频、主动分享与系统备份：录音、导入音频、合成声音、混音及完成的导出文件均在本地处理和保存。应用不会自动将这些音频文件或混音设置上传给开发者或反馈数据库。如果您主动导出或分享文件，文件会通过系统分享界面发送至您选择的目标，后续处理适用该目标的规则。音频文件与偏好设置也可能被纳入 iOS 或设备／账户设置管理的系统备份，这些备份不由本应用控制。
  • 音频播放与后台音频：应用使用 Apple AVFoundation 框架提供播放功能，包括后台及锁屏播放。播放期间不会向开发者发送您的收听历史、录音或混音内容。

用户主动发送的应用内反馈

仅当您点击反馈提交按钮时，应用才会通过 Apple CloudKit 向开发者发送以下信息：

  • 您输入的反馈正文；
  • 您主动填写的选填回复邮箱；
  • 应用版本、构建号、iOS 版本及当前语言／地区设置，用于提供与反馈有关的技术上下文。

提交反馈需要登录 iCloud 账户。反馈保存在本应用的 CloudKit 容器中；CloudKit 会自动维护记录元数据，包括创建信息与应用范围内的创建者用户标识。该标识用于关联记录创建账户及 CloudKit 的记录归属和权限，并非广告标识符。应用不读取您的 Apple ID 邮箱、真实姓名或 Apple ID 凭据；随反馈发送的回复邮箱仅为您在表单中主动输入的邮箱。

提交的信息用于处理与回复您的反馈，以及排查相关技术问题；选填邮箱仅用于回复反馈。反馈记录及其元数据不用于广告或跨应用追踪。CloudKit 由 Apple 托管，记录访问遵循容器的 CloudKit 权限配置。由于反馈可以关联其 CloudKit 创建者及您填写的邮箱，因此不应将其视为匿名记录。

3. 本地存储与系统 API 声明

根据 Apple 隐私清单规范（Privacy Manifest），本应用对系统 API 的调用说明如下：

  • 用户偏好设置（UserDefaults - CA92.1）：用于保存本地混音参数、睡眠定时偏好、收藏及其他应用设置。收藏场景信息也可通过 App Group 在本设备上提供给应用的小组件。应用不会将这些偏好上传到反馈数据库；系统管理的备份取决于您的设备／账户设置。
  • 文件时间戳（FileTimestamp - C617.1）：用于在应用容器内组织和管理自制声音与已完成的导出文件。
  • 本地计时（SystemBootTime - 35F9.1）：用于在设备本地计算音频试听和播放过渡的经过时间，应用不会向开发者发送系统开机时间。

4. 应用内购买与订阅信息

本应用通过 Apple StoreKit 提供可选的“Aura Pro”权益，包括月度与年度自动续订，以及终身一次性买断。当前价格、计费周期及适用于您账户的入门优惠，以 App Store 购买页实际显示为准。免费试用仅适用于符合资格、且购买页显示可用试用优惠的账户。

  • 所有的交易流程、订单结算、付款处理及自动续费均由 Apple App Store 官方系统全权完成。
  • 开发者无法获取亦不保存您的信用卡卡号、银行账户或 Apple ID 支付敏感凭据。
  • 本应用在设备本地读取已验证的 App Store 交易状态，以判断 Aura Pro 权限。基础混音无需 Aura Pro；完整 Pro 音源库与新建 AAC 音频导出需要 Aura Pro。再次分享已完成的导出文件，不要求会员资格当前仍然有效。

5. 不主动索取或追踪的信息

除第 2 节所述的自愿反馈信息外，应用不会为开发者收集而主动索取或自动提取以下信息：

  • 您的真实姓名、手机号码、身份证件号码或 Apple ID 凭据；
  • 您的通讯录、日历日程或备忘录；
  • GPS 精准位置或位置历史；
  • 广告标识符（IDFA）或跨应用追踪指纹；
  • 生物识别数据（面容 ID、触控 ID）或健康诊疗记录。

反馈中的选填邮箱及应用范围 CloudKit 创建者标识已在上文说明。如果您在反馈正文中自愿填写其他个人信息，这些内容也会随反馈提交。请仅提供支持请求所必需的信息。

6. 数据保留与用户控制权

  • 本地声音与导出：您可以在应用的管理页面中删除自制声音及已完成的导出文件。已分享或保存在应用之外的文件，由您选择的目标单独管理。
  • 权限管理：您可以随时在 iOS 的“设置” > “Aura 助眠”中允许或撤回麦克风权限。
  • 删除应用：删除应用会依据 iOS 规则移除设备上该应用本地沙盒中的数据，但不会自动移除系统备份、其他位置保存的文件或已提交至 CloudKit 的反馈。
  • 反馈数据请求：反馈记录会保留在本应用的 CloudKit 容器中，除非在云端进行处理或删除；卸载应用不会删除这些记录。您可以通过 vivi.huang.2026@foxmail.com 请求访问、更正或删除已提交的反馈。请提供足以定位该记录的信息，例如大致提交时间及您当时填写的回复邮箱（如有）。应用尚未实现反馈记录的固定自动到期删除机制。

7. 儿童与未成年人隐私保护

本应用作为通用身心放松与睡眠辅助工具，不以任何 14 周岁（或您所在司法辖区规定的法定年龄）以下的儿童为特定受众，亦不会明知而收集未成年人的任何个人信息。若您是未成年人，建议在法定监护人的陪同指导下使用本应用。

8. 本隐私政策的变更

随着产品功能的持续演进或法律法规、监管要求的更新，我们可能会适时修订本隐私政策。任何重大变更均会在本页面及时发布，并在页面顶部标明最新修订日期。若您在修订生效后继续使用本应用，即表示您已阅读并同意最新版本的隐私政策。
