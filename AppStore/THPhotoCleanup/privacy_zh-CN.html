隐私政策

Photo Cleanup · 拾光

生效及更新日期：2026 年 10 月 12 日

1. 适用范围与开发者

本隐私政策适用于 Photo Cleanup（中文名「拾光」，以下简称“本应用”），由开发者 Tan（以下简称“我们”）提供。本应用帮助你整理照片和视频、查找重复或相似内容、识别可能包含敏感信息的照片、压缩视频及生成实况照片的静态版本。

2. 数据处理概览

本应用无需注册账号，不集成广告、行为分析或第三方崩溃上报 SDK，不进行跨应用跟踪，也不出售或出租个人信息。照片分析、文字识别和媒体处理在设备端完成，我们没有接收照片、视频或分析记录的自建服务器。系统服务仍可能联网：包括 iCloud 原片下载及照片同步、Apple 地点名称解析，以及 App Store 购买和恢复。

3. 照片访问与本机分析

经你授权，本应用读取可访问的照片、视频、缩略图及相关信息，例如媒体标识、拍摄时间、尺寸、时长、收藏状态、相册和照片已有的位置坐标，用于预览、分类、相似度与重复校验、大小计算及整理建议。你可以授予部分照片访问权限；完整扫描与部分相册功能需要完整访问。

Apple Vision 在本机进行视觉和文字识别，可能分析照片中的证件、银行卡、合同或其他敏感文字，用于提示你检查这些照片。识别出的完整文字不会作为文字档案保存或上传；本机会保存相应分类标记等分析结果。此功能不是身份验证，也不能保证识别所有敏感内容。

4. 照片位置与 Apple 地点解析

本应用使用照片已有的拍摄坐标和时间进行地点及旅程归类，不请求设备实时定位。整理结果更新时，地点名称解析可能自动通过 Apple 的 CLGeocoder 服务发送部分照片的代表位置坐标，以获取城市或地区名称；这些坐标可能是精确坐标，并非保证经过模糊化处理。我们不会随该请求发送照片图像或识别文字。

限制照片访问范围可以减少可供处理的照片及其元数据；撤销照片权限可停止后续照片访问。本应用目前没有单独关闭地点名称解析的开关。“仅通过 Wi-Fi 读取云端原片”设置针对媒体下载，不是所有系统网络请求的统一开关。Apple 对这些请求的处理适用其隐私政策。

5. iCloud、保存与删除

当原始资源仅存储于 iCloud 时，系统照片服务可能根据网络条件和应用设置下载原片，以便校验、计算大小或处理媒体。你确认的保存、相册修改及删除操作可能按你的 iCloud 照片设置同步至云端和其他设备；这由 Apple 的照片服务处理。

压缩视频或生成静态照片会创建新媒体，原始媒体的删除需要另外确认。保存结果可能保留拍摄日期和位置；本应用不保证移除全部元数据。卸载本应用不会撤销已完成的照片删除，也不会删除已保存到系统照片的媒体。

6. 本机存储及保留期限

本应用在设备本地保存整理偏好、受保护相册、选择和整理进度、忽略标记、操作历史、媒体标识、分析缓存以及免费使用额度记录。处理过程中还可能生成临时视频或图片文件。这些数据用于继续整理、减少重复扫描、展示历史和执行免费额度。

整理状态与分析缓存目录被设置为不纳入系统备份；其他本机数据是否随设备备份保留取决于系统设置。记录和缓存可能保留至被应用更新、清理或卸载；临时文件在处理结束或系统清理时移除，异常退出可能留下残余。删除应用（而非仅卸载未使用的 App／保留数据）通常会移除应用沙盒记录，系统相册中的媒体需在“照片”中单独管理。

7. 内购与 Apple 服务

Photo Cleanup Pro 使用 Apple StoreKit 提供一次性非消耗型内购，无订阅和自动续费。本应用读取 Apple 验证的交易和购买权益，以解锁功能、恢复购买及处理撤销或退款状态。付款、Apple 账户和支付信息由 Apple 处理，我们不会取得你的银行卡信息或 Apple 账户密码。Apple 可能依其政策保留交易记录；卸载本应用不会删除这些记录。

8. 联系我们及访问本网页

如果你主动通过电子邮件联系支持，我们会收到你提供的邮箱地址、消息及附件，仅用于处理请求、跟进问题及履行必要义务，在所需期限内保留。你可以请求删除这些通信；法律要求保留的情况除外。请勿发送原始证件、银行卡照片或不必要的个人信息。

本政策页面托管于 GitHub Pages，未加入分析脚本或广告。访问网页时，GitHub 可能处理 IP 地址等请求日志；使用 GitHub Issues 时，提交的内容可能公开。相关处理适用 GitHub 隐私声明。

9. 你的选择与权利

你可以在 iOS“设置 → 隐私与安全性 → 照片”中调整或撤销授权，在应用内调整整理偏好或恢复已忽略的建议，并通过删除应用移除本机记录。恢复建议不会重置免费使用额度。你也可以联系我们提出访问、更正、删除或其他适用的数据权利请求；我们无法远程读取或删除仅存于你设备内的媒体和记录。撤销权限不影响此前已完成的操作。

10. 安全与未成年人

本应用依赖 iOS 权限、沙盒及系统文件保护限制数据访问，但任何系统都无法保证绝对安全。请保护设备解锁凭据并备份重要媒体。本应用不专门面向儿童；未成年人应在监护人指导下使用，涉及付费或删除重要媒体时应取得监护人同意。如认为儿童向我们提交了个人信息，请联系删除。

11. 政策更新

我们会因功能或数据处理变化更新本政策及顶部日期。重大变化会通过应用内提示、版本说明或本页面予以说明；需要额外授权或同意的处理会依法另行征求，不以继续使用代替依法必需的同意。
